## Current Project

### [Infants and Incantations](https://github.com/callum-legendre/infants-and-incantations)

**Infants and Incantations** is a solo C++ vertical-slice prototype built
using [OGRE](https://www.ogre3d.org/) with SDL2 integration.

The project began as a way to deepen my understanding of C++, game-engine
architecture, and working within an unfamiliar codebase. Limitations in
OGRE's macOS support led me to integrate SDL2 for window and input handling,
requiring me to work through platform-specific rendering and
engine-integration challenges.

The project has given me practical experience with engine architecture,
graphics/rendering systems, CMake, resource management, and debugging
third-party code.

For a deeper technical breakdown, including the macOS and SDL2 integration,
see the [project README](https://github.com/callum-legendre/infants-and-incantations/blob/main/README.md).
