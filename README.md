Current project:
Infants and Incantations is a solo vertical slice prototype using [OGRE (Object-Oriented Graphics Rendering Engine)]([url](https://www.ogre3d.org/)) with SDL2 integration. The project began as a way to deepen my understanding of C++, game-engine architecture, and working within an unfamiliar codebase. During development, I encountered limitations in OGRE's macOS support, which led me to integrate SDL2 for window and input handling and work through several platform-specific rendering and engine-integration challenges.
The project has given me practical experience with engine architecture, graphics/rendering systems, CMake, resource management, and debugging third-party code.
For a deeper technical breakdown, including the macOS and SDL2 integration, see the project's README.
